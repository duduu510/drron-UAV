# 本机新计算的仿真基线样例

这不是历史西安1011任务方案。基于用户当前13线路/248站/275区间数据，在明确研究假设下实际计算。

- project.json：冻结的仿真输入；保留原项目来源。
- solution.json：实际输出，39/977物理任务，未完成，不可发布。
- summary.json：汇总与假设，不是可导入的完整方案。
- reproducibility.json：两次运行逐事件复现检查。

可先在软件「批量导入向导」导入project.json，再在「方案库」导入solution.json。它们属于同一输入哈希。重新导入同项目ID会被拒绝而不会覆盖；实际道路、服务许可和硬件参数仍待核验。
