# Reproducible simulation baseline v1

User chose current real network as a new reproducible baseline. No original solver exists. Build a conservative greedy station-return model, explicitly simulation-only. Never call this the original GRASP or real operational dispatch.

## Config keys and defaults (research assumptions, editable)
team_count=4 (one vehicle + one drone per team); depot_station_id user-selected actual station; max_length_km=.5; window_min=240; seed=7; vehicle_speed_kmh=30; drone_speed_kmh=18; drone_endurance_min=40; vehicle_range_km=100; drone_min_soc=20; vehicle_min_soc=10; swap_min=2; swap_stock=8; launch_min=.5; land_min=.5; vehicle_fixed_yuan=400; drone_fixed_yuan=50; vehicle_km_yuan=1.5; vehicle_min_yuan=1; swap_yuan=6; assume_service_at_all_stations=False (must opt in). All numeric values finite. Positive speeds/endurance/range/window/max_length; SOC in[0,100); counts integer with team_count1..64,swap_stock>=0,seed>=0. Other times/costs>=0. Missing fields use DEFAULT_CONFIG except depot ID and explicit service assumption.

These are transparent simulation parameters, not measured hardware data. The ground route is an undirected rail-network shortest-distance proxy because actual road data is absent. No hidden use of passenger timetables. No UAV cross-vehicle transfer in v1. No real-time telemetry. No publish capability.

## Model
Split real segments using existing generate_tasks; physical_task_id pairs direction alternatives, inspect each physical group once. Every sortie launches at an allowed original station endpoint, flies along its segment to one piece, inspects that piece, returns to SAME launch station and lands. A virtual node NEVER provides service. One vehicle carries one drone; vehicle waits throughout sortie. Ground travel is shortest-path network proxy. Every used team returns to the selected actual depot station within window with vehicle SOC margin. Drone SOC decreases linearly by total active flight/launch/land minutes / endurance*100. Ground ride keeps drone SOC unchanged. Vehicle SOC decreases linearly by distance/range*100. Battery swap consumes one spare and full swap time; no recharge. Explicitly record all these assumptions in result.

Choose tasks in seeded deterministic order; for each physical group choose feasible team/orientation/launch endpoint minimizing projected finish+return with deterministic tie-breaks. Cache graph shortest paths. Reserve return time and SOC before admitting each sortie. Skipped tasks retain diagnostics; incomplete result is honest and not a complete-cost candidate. No global optimality claim.
