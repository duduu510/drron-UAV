## 还需提供或明确

1. 原274区间/1011任务的筛选和分段规则（当前275区间按0.5km产生977个物理任务、1954个方向候选）。
2. 四车场及责任区、可保障站点名单、真实设备资源和电池兼容关系。
3. 无人车地面道路距离/时间、无人机巡检速度、空飞/悬停/作业耗电与安全余量。
4. 原求解器已缺失；目前实现了新仿真贪婪基线，后续完整算法仍需确认模型。旧汇总指标不构成新算法验收的唯一依据。
5. 完整方案格式至少包含运行ID、输入哈希、任务指派、车机事件、起终节点、分钟时轴和SOC。

这些资料按原始数据、历史结果和当前软件输出分别管理。软件开发可先继续；完整可行求解验收需补齐上述输入。
